How It Works

The model follows a classical and lightweight NLP pipeline:

1. Text Cleaning Arabic normalization, HTML/URL removal and whitespace cleaning.
2. TF-IDF 100,000 unigram and bigram features.
3. Linear SVM Linear Support Vector Machine for binary classification.
4. Browser Inference The model runs locally using JavaScript without a backend server.

Dataset

Reviews 329,967 cleaned reviews
Task Binary Arabic Sentiment Classification
Features 100,000 TF-IDF features
